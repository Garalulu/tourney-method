# Contributor documentation

This folder contains the documentation needed to understand and contribute to
Tourney Method. Production hosting and infrastructure procedures are
intentionally maintained outside the public repository.

- [Development](DEVELOPMENT.md) — local workflow and common commands
- [Architecture](ARCHITECTURE.md) — application boundaries and request flow
- [Testing](TESTING.md) — database safety and test suites
- [Queues](QUEUES.md) — background-job conventions
- [Refactoring roadmap](ROADMAP.md) — planned structural improvements

Documentation should describe the current code. Update the relevant page when a
change affects architecture, contributor workflow, tests, or queue contracts.
