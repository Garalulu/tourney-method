# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository. If that is
not available, email `pso9809@gmail.com` with:

- affected version or commit;
- reproduction steps;
- expected impact;
- any suggested mitigation.

You should receive an acknowledgement within seven days. Please allow a
reasonable remediation period before public disclosure.

Never include real credentials, access tokens, private user data, or production
database contents in a report.
